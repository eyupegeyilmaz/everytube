# 🎵 EverYTube - YouTube Tabanlı Müzik Streaming Uygulaması

YouTube'dan müzikleri dinle, playlist oluştur ve favorilerini kaydet!

## 🚀 Özellikler

- 🔍 YouTube'da şarkı ara
- ▶️ Doğrudan YouTube'dan müzik çal
- 📝 Playlist oluştur ve yönet
- ❤️ Favorilere ekle
- 👤 Kullanıcı hesapları
- 🎨 Modern arayüz
- 📱 Responsive tasarım

## 🛠️ Teknoloji Stack

### Backend
- **Node.js** + Express.js
- **MongoDB** - Veritabanı
- **YouTube API** - Müzik kaynağı
- **JWT** - Kimlik doğrulama

### Frontend
- **React.js** - UI Framework
- **Tailwind CSS** - Styling
- **Axios** - HTTP İstekleri

## 📦 Kurulum

### Backend
```bash
cd backend
npm install
npm start
```

### Frontend
```bash
cd frontend
npm install
npm start
```

## 🔧 Ayarlar

`.env` dosyası oluştur:
```
YOUTUBE_API_KEY=your_api_key
MONGODB_URI=mongodb://localhost:27017/everytube
JWT_SECRET=your_secret_key
PORT=5000
```
